# genmedia-skill

A Claude Code skill that replaces subscription media-generation aggregators (Higgsfield-style, $49–79/month) with **pay-as-you-go** generation over [kie.ai](https://kie.ai) and [fal.ai](https://fal.ai). Images for ~2–4¢, 5-second videos for ~28¢, every asset and its prompt saved to your own disk forever.

## The idea

Media aggregators don't make AI models — they wrap other companies' APIs (Nano Banana, Kling, Veo, GPT-Image…) behind one account and charge a subscription. Pay-as-you-go aggregators (kie.ai, fal.ai, WaveSpeed) do the same wrapping but charge per generation. An AI agent that can read docs and write code can be the front end itself. This skill is the instruction manual for that.

Credit where due: the concept comes from [Jay (Robo Nuggets)'s video "I replaced Higgsfield with one Claude skill"](https://www.youtube.com/watch?v=9C4TRbucmhQ). This is an independent implementation of the idea he demonstrates. Two write-ups (live pages):

- **[The development journey](https://az9713.github.io/genmedia-skill/genmedia-development-journey.html)** — the full build story: model routing demystified, why this is a skill and not an MCP server, real measured costs, and an honest list of what you give up vs. a polished subscription product.
- **[Interpreting Jay's /generate design](https://az9713.github.io/genmedia-skill/jay-generate-skill-interpretation.html)** — analysis of the original skill shown in his video.

## What's in the box

| File | Role |
|---|---|
| `SKILL.md` | The skill: hard budget rules, cheapest-first routing (kie → fal), provider calling patterns, output + sidecar-logging conventions |
| `models.md` | Cache of verified model recipes with **measured** real costs — grows automatically as the skill uses new models |
| `gallery.js` | Zero-dependency local gallery (`node gallery.js` → http://localhost:7777): masonry grid, hover-play videos, per-item prompt/model/cost panel |

## Install

1. Copy this folder to `~/.claude/skills/genmedia/`
2. Put API keys in your project's `.env` (never committed):
   ```
   KIE_API_KEY=...        # https://kie.ai/api-key
   FAL_API_KEY=...        # https://fal.ai/dashboard/keys
   ```
   Either alone works; the skill falls through to whichever provider is available.
3. In Claude Code: `/genmedia three product shots of X, budget $0.50` — or just ask for media in plain words.

Works in other agents too (Codex etc.): point the agent at `SKILL.md` and it follows the same procedure.

## Design decisions worth stealing

- **Budget is a hard ceiling**, checked before every API call. Video always gets a cost quote and waits for an explicit "go".
- **Schemas are fetched, not memorized.** Unknown model → fetch the provider's own docs (kie: `docs.kie.ai/llms.txt`; fal: `https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=<model-id>`), use, then cache the verified recipe in `models.md`. Looked-up knowledge can't go stale.
- **Sidecar JSON next to every file** (prompt, model, provider, params, measured cost) — provenance is never lost, and the gallery reads it.
- **Verify on disk.** A clean API exit is not success; the file must exist with non-zero size.
